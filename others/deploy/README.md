# 部署与迁移准备

当前只提供配置模板与迁移要求，尚无可启动服务或容器编排文件。

A 接入框架后交付：同一服务的本机/云端配置、HTTPS、数据库与文件备份恢复、同引擎迁移和版本回退工具。按锁定版本构建应用和推理工作进程，补齐实际命令。

本地手机联调使用受信任的本地 HTTPS；云端使用正式域名证书。主密钥在服务端独立保存，不写入数据库备份或客户端。学校 AI 配置单独加密与授权。

数据库切换：连通性与版本检查 → 暂停写入 → 备份 → 导入数据库和文件 → 核对 → 切换 → 恢复写入；校验失败保留旧库。监控节点继续留本地。

环境模板中的所有值均为占位符；后续配置加载器必须拒绝占位主密钥。
