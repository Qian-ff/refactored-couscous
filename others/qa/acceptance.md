# 验收清单

## 准备阶段

- 四个顶层目录、设计文档、契约入口、任务书、配置模板可读取。
- 准备检查和 Git 工作流集成测试通过。
- Git 作者采用用户提供值；main 有准备提交；B–G 独立分支与工作区准备就绪。
- 依赖、密钥、数据、模型、报告与 worktree 正确忽略；配置示例可追踪。
- 环境报告区分已确认、缺失、未测试；不会启动、下载或安装模型。

## 业务阶段

- 三种平台乘三种角色九种组合：各角色首页/导航/功能明确，角色切换及直接访问页面权限正确；移动布局与原生能力分别实测。
- 三角色课件搜索真实可用；中文关键词、标题/正文匹配、课程/类型筛选、分页、清空、无结果和失败重试符合已实现契约。
- 搜索先做学校/学院/课程授权，再返回总数、片段、建议词和结果；预览/下载直链、伪造课程参数、授权撤销和身份切换不泄露前一或越权资源；学生不获得答案、草稿或监控权限。
- 课程、名单、题库、培训记录和告警等模块的搜索/筛选随模块实现验证；未提取文本的课件不伪造全文匹配。
- 两校同名学院、相似学号：查询、修改、下载相互隔离。
- 同校学院按授权范围操作；跨学院课程只暴露必要数据。
- 加退课、审批、换教师和归档保留历史；撤销授权立即影响实际接口。
- 草稿题审核发布、局部重生成、版本快照和出处可追溯。
- 服务端判分、关键题、必修关卡、幂等及自动培训记录正确。
- 三端真实录音、文字确认、出处、播报、停止、设备拒绝与网络失败可处理。
- 上传和实时监控产生证据；可确认/排除/关闭；仅去身份摘要进入云 AI。
- 风险事件由教师审核转教学案例；原始监控不发布给学生。
- 更换学校 AI 接口不影响其他学校；客户端包及日志不含服务端密钥。
- PostgreSQL 迁移前后记录和文件一致，失败回退可用。
- Windows 安装、安卓实体机安装及网页/手机布局实际验收。
- 在干净目录或机器运行发布包，确认不引用开发目录；后端另部署并可达。

## 目标与证据

首批目标为 100 账号、20 普通业务并发、一路实时监控；重型任务排队。记录硬件、版本、样本、延迟、失败、误报和内存。

烟火固定独立测试集目标 Precision/Recall 均不低于 0.80，覆盖白墙、蒸汽、反光与遮挡。这是试用目标，不是当前实测成绩或工业消防标准。未达标继续修正并保留实验性标识。

每项报告标明：未实现 / 已实现待测 / 实测通过 / 失败或阻塞；准备脚本通过不等于业务通过。

每轮功能合并另外验证：对应轮次的一键入口及通用入口可用、后端真实健康、受影响的三端产物已重建、打开的是本轮版本。保存启动日志和功能证据。第2次/第3次云端推送的门槛与授权见 ../docs/git-workflow.md；未推送成功不得记为云端已备份。
