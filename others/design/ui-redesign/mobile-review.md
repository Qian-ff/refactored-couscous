# UI-2026.10-v1 移动第二遍检查与冻结审计

网页方向已获用户明确批准，证据在approval.json。此阶段按同版风格补充移动设计，不增加第二次审批。桌面批准提交b67ad77的prototype.html/css/js、字体来源和55张PNG均校验未变。

## 设计与逐图检查

先按mobile-plan.md确定参数、布局及自审，再编写独立mobile画布。共16组参考：登录、首改、学生课程/菜单、账号/筛选/菜单、新建账号、授权、身份切换、教师目录、班级名单、CSV通过/错误、归档确认、全部通用状态。每组有首屏及长页，4组长表单/流程另附滚动补图。

逐组检查首屏，并检查学生长页、全部状态长页、账号授权与CSV滚动尾部：中文可读、字段标签完整、错误换行、操作可达、无横向页面滚动。保留青蓝与器材体积，课程小封面横排，管理记录用分隔线及字段标签，没有新增统计、成绩、进度或未实现业务。

修正两类真实发现：文字“编辑”的命中宽度不足44px，班级返回链接高度仅20px；补齐触屏尺寸并重新出图/检查。字段顶端对齐，移动记录值14px，输入16px；只读、待发布和未开放均有明确文字。长授权表单首屏尚未滚到底时，底部动作保持固定，滚动补图展示完整新增授权按钮。

## 自动证据及覆盖

- qa-mobile.json：16组出图，字体、页面宽度、工作区裁切、原表格字段/动作文本保留、可见交互44px、浏览器错误和请求拦截均通过；包含浏览器版本、输入SHA256、图片SHA256和尺寸。
- responsive-audit.json：全部53个已有画布分别读取原表格，再核对390px记录字段和动作文本无丢失；检查宽度、裁切、触控及浏览器错误。此审计不是对53个手机画面的人工逐像素批准，展示参考为16组。
- 新建账号在390×520浏览器小视口和24px模拟安全区下检查：末输入下边缘约371.6px，动作区顶约423px、底520px，无互相遮挡。这里只证明浏览器布局，不证明原生键盘行为。
- 每次移动渲染前后核验批准桌面来源及55张PNG哈希；没有覆盖批准图片。

## 冻结与边界

颜色、字体/许可、字号字重、间距、栅格、圆角、边框、阴影、图标、导航、表单、表格、分页、弹窗、状态与三端要求已归入tokens、design-spec、state-spec和platform-spec。functional-map对应53幅来源，migration-checklist细化全部已存在动作的位置、角色和服务端行为。handoff提供A/D/B/C/F接续及D-UI执行起点，freeze-manifest锁定文件。

真实接口、会话、权限、键盘/读屏、软键盘、系统返回、Windows缩放、三端构建/运行仍由D/B/A/F在迁移后验证。没有待下载的框架或模型，本设计阶段不要求用户安装新依赖。
