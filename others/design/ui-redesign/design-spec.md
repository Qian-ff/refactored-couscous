# 安研通 UI-2026.10-v1 设计规范

状态：网页方向已获用户明确批准；移动稿与本规范按该方向补齐，用于A接收、原D实施。桌面批准提交b67ad77cd49c2b5f99d2037e5828c29433ea66a6；批准原文见[approval.json](approval.json)。设计图全部为合成示例，不是产品完成证明。参数的机器版本见[tokens.json](tokens.json)，行为状态见[state-spec.md](state-spec.md)，三端要求见[platform-spec.md](platform-spec.md)。

## 1. 主题、品牌与信息组织

采用“实验记录簿＋实验室轻立体”。稳定的青色导航像记录簿书脊，课程目录是索引，班级名单与管理表格是工作页。器材体积和阴影集中在登录/学生课程，管理列表不重复加入装饰或大阴影。没有数据支持的统计卡、成绩、进度、AI回答和监控状态不出现。

品牌、窗口标题为“安研通”，英文为LabConnect；正式材料全称“安研通——实验室安全智能协同管理平台”，宣传语“让安全管理更智能，让实验协同更畅通。”。“设计稿”“示意数据”和版本放在图册及交付说明中，不混入正式产品工作流。

统一术语：课程目录、教学班、目录所有者、主讲教师、协作教师、学生账号邀请、班级邀请码、归档。目录所有者与主讲教师分别授权；UI称主讲教师，接口is_primary等现有字段不改名。学生账号邀请用于开通账号，班级邀请码用于已开通学生加入班级，不能混为一项。

## 3. 网格、间距与层次

桌面导航208px；逻辑宽度≤1000px时184px；≤700px进入移动导航。工作区左右38px、顶部32px，最大内容容器1490px。手机左右16px，表单内20px；页标题到首工作区约20–24px。基本间距4、8、12、16、20、24、32、40、48、64px，18/22/38等保留图稿的光学调整，不机械强行凑齐。

圆角按层次：标签5px、输入8px、按钮9px、记录面板11px、卡片12px、面板13px、移动短弹窗14px、主视觉16px、桌面对话框17px。手机全屏表单/长弹窗圆角0。表格、记录行不各自加阴影；悬浮对话框、品牌标记与主按钮保留轻微体积，阴影精确值见tokens。

公共壳只提供一次main和工作区内边距。D接入BusinessPage时移除重复main/max-width/padding；业务Section保留其标题和状态，不能叠出两层整页空白容器。区块标题、工具条、结果与分页形成连续工作区，不把每个操作拆成相同卡片。

## 4. 导航、身份与页面结构

桌面侧栏保留品牌、学校空间、当前可用入口；顶部显示路径、工作身份与账号。学生是独立身份，不提供教职切换；兼任教师与管理员的账号只列服务端已有授权。切换必须先收窄/更新服务端会话，再显示对应导航和数据；不能只换顶部文字。

手机顶部72px加安全区，品牌、学校、当前身份与44px菜单入口。侧栏变为带范围说明和退出操作的抽屉。学生现阶段为课程、未开放的安全学习/学习助手/培训记录四个位置；未开放项不是可进入的空壳页面。未来新增已实现功能由D按批准规范扩展，不提前把后续五入口当成现状。教师与管理员手机上保留完整授权功能，以导航抽屉和页面工作区操作。

教师课程页采用目录索引＋授权教学班。手机目录收为明确的可展开选择区，展开后搜索、目录列表、新建课程仍可达。班级详情采用概览/学生名单/申请审批/教师协作标签；协作教师能查看教师关系但不能修改关键授权。活动/归档筛选与目录/班级分页各自保留，不能因为改版改成客户端当前页过滤。

## 5. 组件规范

| 组件 | 视觉与交互 |
| --- | --- |
| 主按钮 | 青底白字，主要任务每个局部区一个；桌面高≥44px，移动命中宽高均≥44px。待提交显示明确动词与进行中状态，防止重复触发。 |
| 次按钮 / 行动作 | 白底结构线；低层动作可用文字样式，但手机仍有44×44px命中区和足够间隔。危险动作用红色说明与明确确认，不将所有删除/停用混成一个菜单项。 |
| 禁用 | 灰色且不可激活，必要时旁边说明原因；pending、无权、归档、未开放分别表达，不共用“不可用”。 |
| 表单 | 标签在上，必填用*与语义属性；错误贴近字段且保留合法输入。桌面两列，移动一列。输入高44/移动46px；选择、复选与开关的外层命中区≥44px。 |
| 只读 | 浅灰面与可读文字，不用可点击开关外观表达只读规则。账号和目录代码等不可变字段保留只读，不能通过美化开放修改。 |
| 搜索与筛选 | 输入、搜索动作、筛选、清空可识别；手机搜索始终可达，筛选展开显示身份/学院等现有条件，任务按钮不藏在筛选里。中文IME组合期间不误提交；清空/换条件重置相关页码。 |
| 表格与记录 | 桌面表头、行、行操作、分页连续；手机变为姓名/账号标题＋有标签的数据＋独立操作行，所有字段/动作保留。表内必须横滚的原始长文本在局部滚，不横移整个页面。 |
| 分页 | 总数和每页数量来自真实响应/查询，图中10条为示例，不替代组件当前20条等真实参数。筛选/身份变化回到有效页，不把“本页无数据”称为“全校没有”。 |
| 状态标签 | 短文字＋语义色，必要时状态点；不把“账号启用”和“课程开放”混为同一个业务状态。 |
| 课程 | 封面与课程学院/代码/名称/主讲来自可用数据；没有内容时明确待发布，不虚构进度条。学生390px为小封面横排，管理页优先工作信息。 |
| 对话框 | 短确认居中，明确对象、影响、取消和具体动作；焦点进入标题/首控件，Tab圈定，Escape/返回按状态关闭并恢复触发点。不能只靠点背景退出。 |
| 抽屉 / 长表单 | 桌面右侧640px；移动全屏，固定标题和底部动作，正文独立滚动。dirty离开确认保留输入，提交结果不明确时保留原请求；软键盘下仍能滚到当前字段和动作。 |
| 通知 | 区分成功、警示、错误、离线；提供用户能执行的下一步，不用alert替代整页状态。保存成功只在服务器确认后出现。 |

复选、选择、表单标签在静态画布中部分为展示元素，D实现时必须使用语义input/button/label、对应id/for及错误关联；不得把纯div外观直接当成可用控件。弹窗恢复焦点、屏幕阅读器通知、路由和真实保存均须在产品实现中验证。

## 6. 可访问性、动态与长期使用

所有实际按钮、链接、输入都有清楚名称、可见蓝色3px焦点和约3px偏移；不移除键盘轮廓。正常小字与背景保持可读对比，错误不只换边框。图标纯装饰时隐藏语义；有意义插图有简短替代说明，同义正文旁的器材图可装饰处理。长列表保留语义顺序，记录字段的标题/值关系不因移动重排丢失。

默认没有自动页面/卡片入场动画。展开、选择、关闭等用户动作可用约160ms反馈；prefers-reduced-motion时直接切换，不用持续漂浮的器材动画。高缩放时允许标签和帮助文字自然换行，不固定文本高度。筛选收起、滚动和弹窗内焦点不应导致页面意外跳回顶部。

后续新增UI必须使用frontend-design并沿用本规范，自主设计、实现、截图自查；通常不再逐页请求审美批准。显著改变既定视觉、业务含义或权限时再确认。新增功能的设计不能被图稿中的未开放状态永久限制，但必须以真实模块交付与A放行为前提。
