# 悬浮助手状态、会话与偏好

UI-ASSISTANT-2026.10-v1.1。显示状态、业务可用性、音频和请求分别管理，不能用一个“关闭”枚举混用。正式公共类型归A；此文件锁定行为语义，尚未实现的HTTP不加入OpenAPI。

## 1. 状态与转换

| 触发 | 显示/内容 | 音频、请求及数据 |
| --- | --- | --- |
| 登录确认且偏好开启 | 胶囊；恢复本设备合法位置 | 不自动问答、录音或播放；打开后才读取有权历史 |
| 点文字入口 | 恢复同一对话面板；手机先小窗 | 保留固定范围、草稿，不创建重复会话 |
| 点语音入口 | 展开录音操作；手机全屏 | 显式用户操作后请求麦克风权限；开始/停止/取消清楚可达 |
| 手机点输入 | 同一实例全屏 | 保留当前内容与焦点，不重发已有问题 |
| 收回小窗 | 手机全屏→小窗 | 保留草稿和对话，不因重排重复请求 |
| 收成胶囊 | 记录上次面板类型 | 立即停止录音/TTS；取消未完成录音；已有识别文字保留；文字问答可继续 |
| 拖到边缘 | 收成胶囊，隐藏80px、露48×56 | 与收起相同；把手只恢复窗口 |
| 生成在收起期间完成 | 只显示轻量提示点 | 不自动展开或播报；点开后消除提示 |
| 设置关闭 | 隐藏全部悬浮形态，设置仍可达 | 停音频、取消/放弃本地请求并尽力取消服务器任务；晚到结果不重新显示或播报 |
| 再开启 | 胶囊，保持配色/偏好 | 重新确认可用性；不恢复任何旧录音或自动播报 |
| 普通页面切换 | 实例和已有对话范围保持 | 不能将新页面课程悄悄写入旧对话；新对话才继承当前授权班 |
| 切学校/服务/工作身份、退出或撤权 | 清旧实例上下文与内容；会话重新确认 | 立即停音频，推进会话代次，取消旧请求；不等待远端取消成功才清界面 |
| 后台/失焦应用 | 不跨其他软件显示 | 立即停录音/TTS；保留已有文字；文字回答允许继续，返回前台不自动播放 |

## 2. 可用性与失败

服务端会话无效优先于全部本地状态。偏好关闭则保持隐藏；偏好开启后，考试gate优先于普通问答内容。学生gate为paused或unavailable/无法核实时，停问答、识别后续问及播报，遮住并从当前渲染树移除历史/回答；新建、历史、胶囊语音、引用等入口不能绕过。缓存查询立即取消或标为失效，晚到结果在显示前再次校验。考试结束仍须服务端确认allowed后重新读取有权内容，不直接露出旧缓存。

学校未配置时显示“本校尚未开启AI助手”，不伪装离线或自动切换模型；该状态的图片不提供历史/新建绕路入口。普通课程保持可用。断网、权限拒绝、额度不足、模型/ASR/TTS失败分别有真实说明与合适的重试/改用文字入口，不显示虚假“已保存”或“播放成功”。请求结果不明时不重新创建重复会话/消息，按正式幂等策略查询或重试。

对话层另须提供加载、空历史、无授权班级、无权限/授权撤销、资料不足及引用版本不可用状态。空历史给新建入口；无权限不继续展示旧消息正文或私有资料名称；资料不足明确说明，不编造引用。删除/清空先确认，成功后使相关请求失效；晚到消息不能复活已删除对话。

## 3. 语音生命周期

沿用PlatformBridge和既有16kHz、单声道、PCM16 WAV协议。未开始时不后台监听；停止后识别、展示可编辑文字，用户确认才提交问答。取消录音或未完成的识别任务不产生一条问题；已识别草稿在当前有效会话内保留。原始音频处理后默认删除，不作为聊天历史保存。

文字提问只显示文字，用户可播放单条回答；语音提问仅在自动播报偏好开启、当前窗口展开、应用前台、会话/对话/任务代次一致且gate仍allowed时自动播报。收起、吸边、关闭、后台、切身份和考试暂停均调用停止/取消；恢复不会自动续播。权限被拒绝、无中文语音或桥接失败有反馈，并保留文字方式。静态原型没有调用这些真实设备接口。

## 4. 本设备偏好与隐私

偏好版本1：enabled=true、theme=white、autoSpeakVoiceAnswers=true为默认。使用规范化服务origin、school_id、user_id及本设备本地profile共同隔离。工作身份切换清内容，但同账号的个人配色/开关可沿用。位置只保存归一化坐标、吸边侧和上次布局类型；刷新展示胶囊，不恢复活动音频。

可用localStorage或F提供的本地配置保存这些非敏感UI字段；不存Bearer、模型密钥、消息正文、原始录音或跨设备历史。损坏/旧版偏好回退默认，未知配色回退白色；本地存储失败时明确提示本次有效、无法记住，而不是宣称已永久保存。无服务端个人开关同步，其他设备不被关闭。

## 5. 服务端文字历史与范围

C提供个人会话列表、读取、新建、继续、删除和清空；默认保留至本人删除，后续学校保留策略另由A/C接入。本版不因新增历史功能授予管理员任意阅读他人私聊的权限。每次列表、读取、检索、引用和任务执行/返回均验证学校、账号、当前工作身份和教学班/资料授权，学生同时验证全账号考试gate。跨设备继续同一服务端会话，但不共享客户端录音/未提交草稿。

新对话的course_id由当前已授权教学班上下文提供，并由服务端再次验证；无当前班先选择。已有对话固定course_id，换班开启新会话；引用固定版本页/段。退出后服务器历史按授权保留，但客户端清理消息、草稿、范围和查询缓存。取消只是尽力终止任务，不能把取消回执当成所有远端计算必已停止；客户端必须独立阻止迟到结果产生显示/播报。

## 6. 返回与焦点

先由C处理当前引用/选择器/确认等内部临时视图，再由D按全屏→小窗→胶囊处理，最后交F/路由进行正常应用返回。设置关闭后返回页面，不创建一条假聊天路由。删除有确认；未提交输入在同一有效会话内保留。关窗口、系统返回、刷新、导航唤起均不得制造第二实例或重复发送。
