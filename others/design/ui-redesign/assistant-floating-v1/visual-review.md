## 本轮处理的可用性问题

1. 纯图标画面也先显式加载已批准字体，避免“画面没用到文字”使字体检查误报。
2. 暂停态隐藏历史/新建操作，胶囊语音动作也保持暂停；新对话继承当前班，没有班才先选范围。
3. 手机按钮实际命中尺寸达到44px；开关视觉轨道28px，但整个按钮高44px。
4. 清空全部历史与删除当前对话分开确认；关闭设置可回页面，再由账号入口恢复设置。
5. 图册每张候选只出现一次，移动背景的助手占位只在浏览器内调整，旧源文件和图片未改。
