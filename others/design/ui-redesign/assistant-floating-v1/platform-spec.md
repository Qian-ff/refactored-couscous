# 三端共享与真实适配要求

UI-ASSISTANT-2026.10-v1.1。三端都在安研通应用内部悬浮，不创建跨软件置顶窗口、Android系统悬浮服务或悬浮权限。网页和Windows使用同一前端；Android复用同一状态与课程/考试规则。

## 1. 共享运行与正式资源

D拥有唯一宿主/路由及公共组件，C提供助手内容与业务，F通过既有PlatformBridge实现设备能力，A维护公共协议/生成类型。正式字体、图标和样式迁入产品前端范围，保留来源许可；构建/安装后不依赖others设计工作树、开发服务器或Git。原型的合成数据、脚本定时器、静态背景、模拟系统框和connect-src none不得直接覆盖正式产品。

同一账号三端读取同一服务端文字历史，界面开关/配色/自动播报只保存在各设备。三端都用真实服务端权限和考试gate，不因本地窗口形态或平台不同而改变规则。

## 2. Windows

维持现有Electron应用窗口和安装流程，在其内容区悬浮；小窗/吸边相对内容区边界，不移到操作系统桌面之外。F检查100%、125%、150%缩放及现有最小窗口，记录CSS逻辑尺寸、实际窗口和产物源码版本；不能把deviceScaleFactor截图称作系统实测。

键盘、鼠标与触控板均可操作标题拖动、正文滚动、历史、引用、长输入及设置；窗口缩放后位置重新限制。原窗口关闭/最小化和后台变化通知助手停音频。F只为可信应用来源配置必要麦克风权限，不为适配一次性放开所有权限或任意外部页面。中文TTS失败有真实文字反馈，不自动改用云服务。

## 3. Android与手机网页

F核对Activity/WebView真实可用区域，安全区只计算一次，避免原生与CSS重复留白。显示键盘时使用真实可见视口/resize行为适配全屏，输入、发送、停止和取消都不能被遮挡；不单靠100vh。旋转、手势导航/三键导航、放大字体和小屏均检查。网页在手机浏览器采用相同重排，浏览器的系统返回/权限流程另行验证。

返回事件先给C消费内部选择器、引用或确认视图，再由D处理全屏→小窗→胶囊，最后交回正常站内/应用返回。系统文件选择器、权限提示由系统优先处理；没有站内历史时不循环压入假路由。F不能另造一套助手状态或重建第二实例。

切后台、锁屏、音频设备失去等情况停止录音和TTS；返回后重新核验会话和gate，不自动重启麦克风。语音采集必须真实解码/重采样成约定WAV；不把WebM换后缀。现有样例ASR通过不代表三端采集已通过。
