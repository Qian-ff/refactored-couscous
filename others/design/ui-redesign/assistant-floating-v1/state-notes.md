# 候选 v1 状态说明

本文件解释图片，不是已批准的产品协议；最终规范在图片批准后冻结。

| 操作 / 状态 | 图片方向与预期行为 |
| --- | --- |
| 首次显示 | 128×56胶囊，默认经典白，靠右下且避开导航/安全区 |
| 展开 | 网页/Windows420×560；手机70%宽、43%可用高；正文独立滚动 |
| 输入 | 手机小窗点输入即全屏；完成后可主动收回小窗；桌面直接输入 |
| 拖动 | 明确标题区或胶囊拖动，8px阈值区分点击；边缘16px内吸边 |
| 半隐藏 | 先变胶囊，再露64×56；露出的区域只恢复，不直接触发录音 |
| 恢复 | 恢复上次面板类型和对话，适配当前可用尺寸；不自动收音/播报 |
| 收起 | 立即停音频，已识别待确认文字保留；未完成录音取消；文字生成可继续 |
| 完成提示 | 收起期间生成结束只显示提示点，不自动展开/播放 |
| 个人设置关闭 | 本账号/服务/学校/设备生效；停止音频并尽力取消任务，保留历史及设置入口 |
| 配色 | 白/青绿/蓝/炭灰，只作用胶囊、标题栏、外框；正文浅色 |
| 录音 | 显式进入录音操作；停止后显示可编辑识别文字，确认发送后问答 |
| 播报 | 语音问答默认自动播报，文字问答手动播放；收起、后台停止 |
| 新对话 | 有当前班则直接继承；没有当前班先选授权范围；固定范围显示在标题下 |
| 历史 | 助手内部切换；本账号文字历史三端读取，至手动删除；删除/清空须确认 |
| 考试 | 暂停问答/音频，历史遮住；只显示暂停原因和重新核实入口，不能从历史按钮绕过 |
| 状态不明 | 与考试暂停一样先封住辅导；明确显示“暂时无法核实” |
| 未配置 | 说明本校尚未开启；普通课程继续可用，不伪装为网络故障 |
| 离线 | 说明连接失败、可重试，输入仍保留；不显示虚假已发送或已保存 |
| 麦克风拒绝 | 明确如何开启权限，保留改用文字；不会静默更换引擎 |
| 退出/切身份 | A/C/D接入时清旧代次、旧请求、旧上下文；不能只隐藏窗口 |

原型当前模拟：切换、拖动/吸边、大小切换、配色、设置关闭/恢复、录音确认、完成提示和暂停状态。服务端历史、考试鉴权、跨设备同步、真实音频、实际后台/系统返回仍需A/C/D/F/B实施及真实验收，静态检查不代替这些能力。

## 图片审阅重点

先看web-dialog、mobile-small、mobile-full，再比较theme-*；小窗的目的在于短问答和保留页面空间，长回答通过滚动或全屏查看。两侧半隐藏均有独立图，设置关闭与收起分别展示。Windows100%/125%/150%只验证CSS逻辑布局，不证明实际系统缩放。
