# 安研通悬浮助手：已批准视觉与布局

版本UI-ASSISTANT-2026.10-v1.1，2026-10-22。用户明确回复“批准 v1.1，继续规范与 A 交接”，批准图片提交7a678db1d3eee3055e0b369bb18952abf1d79676，见[批准记录](approval.json)。本规范用于后续产品实施，不代表产品代码或原生验收已完成。

## 1. 视觉与素材

使用已批准的蓝绿教学产品背景，助手采用安静的纯色胶囊、原创线性图标、细分隔线和柔和阴影。浮层内不重复添加实验室插图或统计卡。白、青绿、蓝、炭灰仅改变胶囊、标题栏和外框；正文、气泡、输入仍使用白/浅灰纸面，主要动作仍用安研通青绿。默认经典白。

四款色值、前景色、字体、字号、圆角、阴影和尺寸的机器版本见[tokens](tokens.json)。四款外壳前景对比均≥4.5，普通正文15px、手机小窗14px、手机输入16px；可读性不足时扩展窗口或滚动，不继续缩小正文。中文左对齐，不截断长答案。原字体本地加载并保留SIL OFL来源；图标导出见[素材来源](SOURCES.md)。

## 2. 窗口与定位

胶囊128×56px，两个操作分别是文字对话、语音操作，均有明确标签与至少44×44px命中区。默认靠右下，避开底栏、系统手势区及当前主要动作；学生底栏70px时，胶囊底部至少再留16px并计一次安全区。教师、管理员的导航不同，不强套学生底栏。

网页/Windows默认420×560px，右28px、底24px，可用区域四周至少16px；小窗口按可用尺寸收缩，正文独立滚动，标题与输入保持可达。逻辑宽度≤700px使用手机重排规则，Windows不以系统像素硬编码尺寸，也不擅自提高现有最小窗口限制。

手机小窗宽为可用宽度的70%，高为可用高度的43%，最小高260px；可用高不足360px或无法同时保留控件与内容时直接使用全屏。390×844 Android模拟中扣除系统栏后，小窗约273×342px，属于已批准的约三成屏幕面积；不能把“约360px”写成所有设备固定高度。小窗有展开、收起及输入唤起；长内容在正文滚动。点输入先展开全屏，用户可通过按钮收回小窗，不能因键盘关闭就突然收回。

全屏是同一助手的布局状态，保留对话、草稿、引用及范围，不产生独立聊天页或另一实例。手机全屏填充真实可用视口，系统栏/键盘适配见[三端规范](platform-spec.md)。

## 3. 拖动与吸边

展开态通过标题区拖动，按钮不兼作拖动起点；胶囊可整体拖动，移动超过8px才认定拖动，并抑制结束后的误点击。正常拖动、键盘移动和窗口缩放后，完整窗口仍在可用区域；只有主动拖到左右16px吸边区才进入隐藏状态，不定时自动隐藏。

吸边先收成胶囊，再隐藏80px、露出48×56px；露出的整个48×56px只用于恢复，不直接启动文字或录音。左右两侧使用同一规则和4px以上触控余量；保存上次展开类型与位置，恢复后按当前视口约束位置。键盘/辅助技术须能通过已有菜单样式执行“靠左、靠右、恢复默认位置”等等效操作，不能只支持鼠标拖动。

吸边高度在可用区域内保存归一化比例；旋转、缩放、键盘变化后重新限制到边界。临时键盘视口不覆盖正常布局的已保存位置。刷新/重新登录后以胶囊开始，不恢复录音、播报或旧的全屏输入状态。

## 4. 内容、导航与设置

标题下显示本对话固定教学班范围；新对话有当前授权班则继承，没有则先选择有权班级。已有对话不随页面切换换资料。较长班名在小窗可省略显示，但展开后显示完整名称，不能省略到无法识别同名班。引用展示资料名、固定版本与页/段，点击后重新判权。

最近对话、新建、删除当前及清空均在助手内部完成。桌面在面板内切换，手机在全屏内查看；删除和清空分别确认。个人设置放当前账号设置中，包含显示助手、四款配色、语音回答自动播报，标明当前设备范围。设置关闭后保留账号设置入口；导航中的助手动作在关闭状态下引导到该设置，不擅自重新开启。

公共宿主只提供一次布局容器；C提供内容与状态，不再次创建fixed窗、main或重复内边距。页面正常切换不卸载助手实例。D负责正式导航和唯一宿主，C不得注册独立助手PageRegistration或反向导入D入口。

## 5. 无障碍与图层

所有图标按钮有中文可访问名称，焦点样式清晰，状态不只用颜色表示。按钮点击范围至少44px，纯视觉轨道/小图标可更小。非模态助手允许操作背景页面，不锁住整页焦点；设置和删除确认按对话框管理焦点，关闭后恢复到对应操作入口。

助手位于页面/导航之上、业务阻塞弹窗之下；阻塞弹窗开启时不能穿透点击助手。键盘Tab顺序与视觉顺序一致，Escape按返回层级关闭当前内部视图/全屏/小窗，不能提交危险动作。减少动态效果偏好下取消过渡，不自动闪烁、弹出或播放声音。

后续常规页面沿用此风格自主设计与截图自查；显著偏离本次视觉或改变权限/业务含义时再确认。图片与原型只供参考，真实状态和交接以[state-spec](state-spec.md)及[功能映射](functional-map.md)为准。
