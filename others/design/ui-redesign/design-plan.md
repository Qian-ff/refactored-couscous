# v1 设计计划与第一遍自审

## 主张

安研通是一张组织有序的实验台：课程有清楚的归属，教学班有独立的名单，危险操作有明确的边界。采用“实验记录簿”的信息组织和器材轻立体，保留青蓝色识别。登录/学生课程承担主题表达，密集的管理操作保持简洁。

危险红、待确认橙、成功绿保留语义，不拿品牌色掩盖风险。文字左对齐；数字和状态按同列对齐。主要标题32px/1.35，正文15px/1.65，桌面密集数据表13px/1.65。主要操作至少44px高，焦点清晰。

中文计划采用Noto Sans SC同一字族：标题650、正文400–450、控件500–600，通过字重和节奏建立差异。来源与许可随字体归档；Windows系统字库仅回退、不复制分发。

## 比较过的布局

方案A：仪器控制台。范围与状态围绕大概览区，数据分区并列。它容易让尚未实现的进度/考试数据成为首页主角，因此不采用。

方案B：实验记录簿，作为本轮方向。导航有稳定青色书脊，页标题下直接出现当前任务；课程目录作为索引，班级/名单作为内容，操作以工具条、抽屉与页内标签组织。

登录保留清楚的学校/账号/密码表单，另一侧用原创的实验台、玻璃器皿和护目镜建立轻立体主题。学生课程用课程内容区分封面，不用同一烧瓶按索引换色。业务页不放装饰性统计大数字。

## 对照brief的自审与修正

1. 初稿容易成为“白卡片加阴影”。改为稳定导航书脊、横向工具条、目录索引和内容表格；仅少数悬浮器材/对话框有明显深度。
2. 不用通用首页只换角色名称。学生只有已有课程；教师看到课程目录与授权班级；管理员看到组织与账号的高密度操作。
3. 班级原页连续堆叠多个大区块。改为概览、学生名单、申请审批、教师协作的标签视图，保留全部既有行为；归档和转交的风险说明单独展示。
4. 保留真实的范围、首改、归档、网络错误、冲突及重试提示；不在设计中出现虚构成绩、AI已回答或已检测告警。
5. 轻立体只服务实验室主题，器材图不遮挡文字、表单或数据。没有无意义的序号、全大写标签和每卡片浮动动画。

## 出图后的第二遍检查

逐页检查中文、对齐、密度、权限差异、表单字段、操作保留、按钮状态和画布溢出；保存渲染错误及修正结果。手机稿在用户批准本轮网页后补齐，不用桌面缩图冒充移动适配。
