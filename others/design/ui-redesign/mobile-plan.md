# 移动稿第一遍计划与自审

用户已明确批准网页UI-2026.10-v1（b67ad77），继续补移动稿与规范。移动稿沿用同版主题，保持已批准的桌面图片及prototype源文件不变，以独立mobile样式与画布呈现390px重排。

## 参数与布局

实验青#087F8C、协同蓝#2563EB、工作台底#F5F8FA、墨色#172B3A、纸白#FFFFFF、结构线#DCE7EB。继续使用Noto Sans SC：页标题26/600–650、段落15/1.7、数据14/1.65、表单16/1.5，辅助说明12/1.75；触屏交互区至少44px。左右16px，分区间距20–24px，器材图保留立体体积，但缩小主视觉占比。

学生保留当前真实课程入口与未开放项，不借移动稿提前设计后续五入口工作台。课程封面与信息横排，减少滚动；主视觉变为一张紧凑的实验记录页。管理页采用有字段标签的记录条目，操作独立一行；搜索置顶，筛选按需展开；不将1440px表格整体缩小。

字段与标签左对齐，数字采用等宽数字。侧栏在手机变为带学校/范围的导航抽屉；教师兼管理员才显示已授权身份切换。多字段表单变为全屏编辑页，标题与动作固定、正文独立滚动；风险确认保留居中短对话框，长CSV流程全屏。

## 对照已批准方向的自审

1. 不把“加底部栏＋原表格横滚”当成移动适配。账号与名单改为带字段标签的紧凑记录；仅原始CSV长文本允许局部滚动，页面不横移。
2. 不堆叠空白大卡片。课程用小封面，管理条目用结构线分组，不给每一条独立大阴影。
3. 装饰集中在课程/登录的原有器材图；管理操作保持清晰，与桌面保持同样的层次和语义。
4. 必须保留全部操作与授权边界；筛选可折叠，但导入、新建、名单操作不能因屏幕变窄而消失。
5. 固定导航和表单动作避开安全区与软键盘。手机参考图只证明布局设计；原生返回、权限、真实软键盘和系统缩放留给D/F真实验证。

第二遍逐图检查390px中文、记录标签、按钮44px、弹窗滚动和底部遮挡，并对原桌面来源与图片哈希做不变检查。
