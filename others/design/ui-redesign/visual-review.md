# 网页候选v1第二遍检查

日期：2026-10-21。版本：UI-2026.10-v1。结论：可供用户审阅网页方向；尚未批准或迁入产品。

## 检查与修正

- 全套53个画面以1440px导出，基础视口1000px；长页面保留原高度。两张新建账号抽屉有独立下半部分补图，表单与底部操作完整可见。
- 检视6张全页拼图，并以原尺寸检查登录、学生课程、教师目录、账号列表、协作教师概览、长表单尾部、CSV重试、首次改密与授权抽屉。未见文本盖住控件、表格挤出画布或弹窗底部丢失。
- 给管理表格相邻文字操作增加间距；头像改为姓名首字。配对字段使用顶端对齐，避免有/无帮助文字时控件错位；数字采用等宽数字特性。
- 将偏浅的正常辅助文字、表头、只读输入与占位说明调深，保留既定青蓝主色。禁用项与正常说明分开表现；焦点使用明显蓝色轮廓，保留减少动态偏好。
- 学生无身份切换；学院管理员对兼任管理员账号显示只读。协作教师仍可查看教师关系，但没有教师授权操作；关键设置显示只读标签，避免误认为可直接切换。
- 对照现有代码修正语义：密码8–256位、首改后重新登录；新课程与首班共用初始代码/名称；目录代码只读；班级邀请码按有效期生成与轮换；原主讲转交后失去当前授权；教师协作保留恢复入口。
- 课程与班级仍区分授权，列表按开课中/已归档展示。组织管理按平台/学校/学院显示对应层级，不给学院管理员显示学院维护入口。CSV行号含表头，预览不展示临时密码。
