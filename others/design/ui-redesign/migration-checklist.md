# 既有功能迁移与验收清单

本表与[53幅页面映射](functional-map.md)、[状态规范](state-spec.md)共同约束D/B/A/F实施。静态图中的示例行数、折叠内容、按钮摆放不替代真实业务逻辑；不能因某个控制在样图未展开而删除功能。原则是更换呈现与入口组织，保留现有请求、类型、会话、判权及版本行为。

| 已有功能 | 桌面入口 / 操作位置 | 手机入口 / 操作位置 | 责任与必须实测的行为 |
| --- | --- | --- | --- |
| 学校、账号、密码登录 | 登录右侧表单 | 登录单列，品牌在上 | D：真实失败提示、账号与学号分别对待；不泄露账号是否存在 |
| 服务地址 | 登录“连接设置”短对话框 | 同名短对话框，可滚动 | D/A：保存校验、旧会话清理与重登，保留取消 |
| 首次改密 | 独立改密表单 | 单列改密 | D/B：8–256位且不同于临时密码；确认字段只做客户端一致性检查；成功撤销会话后重新登录 |
| 工作身份与退出 | 顶部身份列表、退出 | 顶部身份面板、导航抽屉底部退出 | D/A：学生无切换；仅列已有授权，切换收窄、清旧查询与缓存；远端退出失败也本地清理 |
| 学生课程 | 我的课程搜索、刷新、课程卡 | 搜索＋小封面横排，课程/未开放项底栏 | D：只显示本人获授权课程；内容待发布/错误/空真实，不能假造学习进度 |
| 课程目录搜索与分页 | 左索引搜索和目录分页 | 展开“课程目录”区域 | B/D：独立目录查询与页码；不把只显示3条的示例当作取消分页 |
| 全部授权班级 / 目录筛选 | 索引标题附近提供“全部授权班级”，选目录后主区提示当前筛选 | 目录展开顶部同名动作，关闭后保留当前筛选提示 | B/D：保留原catalogFilter清空及班级页码重置；此小型控件未在所有样图展开，也必须接入 |
| 活动与历史班级 | 主区状态条件、班级列表及分页 | 搜索/筛选区及记录列表 | B：使用真实archived查询，不将活动和归档结果凭空混合；班级授权独立于目录 |
| 新课程与首班 | 索引底部“新建课程”表单 | 目录展开后新建，表单全屏 | B：学院、主讲、code、title现有字段；目录与首班初始同名同代码；教师首班本人主讲 |
| 已有目录开班 | 主区“开设教学班” | 同一主区任务操作 | B：catalog_id关联；同校教师查找最少2字，指定别人后不默认获得该班访问权；跨学院按学校管理员授权 |
| 目录修改 / 归档 / 恢复 | 主区“编辑目录”，目录状态和管理员负责人字段 | 全屏编辑 | B：代码只读、revision校验；活动班级阻止目录归档；所有者变更不自动转交既有班级 |
| 组织层级与选择范围 | 组织导航、学校/学院/专业标签、工具条 | 导航抽屉、标签、筛选，列表为记录 | B：平台三层、学校学院/专业、学院仅专业；真实学校/学院选项按授权提供，单一范围可只读显示 |
| 组织创建 / 改名 / 启停 | 新建按钮、行编辑、对话框 | 同名按钮与对话框 | B：编码/归属不可在编辑中修改；停用保留历史，学校停用限制全校访问，冲突不能覆盖 |
| 账号搜索与范围 | 账号工具条：学校、学院、身份、关键词、清空 | 搜索常显，其他条件展开 | B：真实query/offset；IME、同身份搜索竞态、切范围失效；不能用前端过滤越权结果 |
| 新建学生 / 教职账号 | 顶部新建，抽屉选择初始身份与资料 | 全屏单列编辑 | B：学生必填学号专业、学生与教职互斥；教师可兼管理员；平台/学校/学院可授角色不同 |
| 账号资料 | 行编辑→基本资料标签 | 记录“编辑”→基本资料 | B：账号只读；可选资料保留；已建立学生学号/专业不清空；本人及上级管理账号按原规则只读 |
| 角色新增 / 撤销 | 抽屉“角色授权”，已有授权行＋新增表单 | 全屏授权标签，逐项动作 | B：角色与学院范围独立提交；学校管理员不能授学校管理员；撤权后旧会话新请求重新判权 |
| 账号停用 / 启用 | 抽屉“账号状态”及确认 | 全屏状态标签与短确认 | B：停用撤销会话；在用主讲先交接；重新启用不是重新建号 |
| 密码重置 | 行快捷入口或编辑区重置 | 记录操作或全屏资料区 | B/D：仅输入新临时密码，不查询已存密码；重置撤销所有会话，下次强制首改 |
| 学生账号邀请 | 创建范围表单、元信息列表、撤销 | 单列表单与记录列表 | B：专业可不限定；有效/过期/次数满/撤销均真实；新码仅生成当次显示，列表不回显 |
| 班级资料与设置 | 班级概览“编辑班级” | 同名操作与短/全屏表单 | B：名称、加入审批、退出审批及revision；协作教师只读，关键设置由主讲或范围管理员操作 |
| 学生名单查询 / 历史 | 学生名单标签，关键词与状态、分页 | 同标签，搜索/筛选、记录分页 | B：在班/退出/移出历史保留；不同班名单独立，协作教师可管理本班 |
| 拉入 / 移出 / 重新加入 | 名单主动作、行操作 | 名单任务区与记录动作 | B：准确本校登录账号拉入，不开放外学院完整账号目录；历史关系不删除，动作后刷新名单/申请 |
| 加入 / 退出审批 | 申请审批标签，状态、分页、同意/拒绝 | 同标签与记录操作 | B：待处理/历史、重复处理返回最新状态；协作教师可审批，归档不可变更 |
| 教师协作 / 恢复 | 教师协作标签，候选搜索、添加、移除/恢复行 | 同标签记录、选择对话框 | B：同校候选最小资料；保留已移除关系；协作教师能看关系但不能改授权 |
| 班级邀请码 | 概览邀请码对话框 | 同名对话框 | B：有效期、重新生成、旧码失效；完整码仅生成当次展示；不存在独立开关接口 |
| 转交主讲 | 概览风险区，经教师选择与确认 | 同风险区与短确认 | B：revision＋服务端判权；原主讲失权并返回授权列表，历史保留；管理员按独立范围判断 |
| 归档班级 | 概览风险区与编码确认 | 同位置短确认，可滚动 | B/D：编码确认仅客户端保护，不新增API字段；关闭新选课/当前学生资料访问，历史在管理授权下只读 |
| CSV账号 / 名单 | 账号顶栏、名单工具条，分别进对应上下文 | 同位置任务按钮，全屏流程 | B：文件＋文本编辑、模板、UTF-8、1MiB/500行、全部预检、行号字段错误、原子提交、旧预检失效、同键重试全部保留 |
| 通用状态与反馈 | 当前区块或顶层通知，不额外发明新业务页 | 原位换行、操作可达 | D/B：加载/空/失败/离线/无权/未配置/未开放、pending/冲突/结果待确认；真实结果才显示成功 |

## 文件所有权与接入次序

1. A先接收冻结设计、核对批准证据与SHA，发布D-UI基线并明确跨文件交接。D唯一维护App/main/routes、公共设计系统与web/tests/d-learning；A维护公共契约/SDK、共享测试配置/辅助、后端总入口和依赖。
2. D先完成公共壳与组件，再由B迁移features/admin、features/teaching展示层；不能同时各造壳/身份层，不能整段替换含请求/会话逻辑的ui.tsx。若A授权D接管某具体B文件，应记录唯一修改者和交回条件，不能靠“全仓库权限”默认并行编辑。
3. C当前不实现新增功能，仅在恢复时沿用本规范；未来内容/助手与学校AI设置仍属于C。F迁入包内资源并负责原生适配，A重建验收。G保持独立验收分工。
4. 三端共用正式接口、数据和服务端规则。样图字段、总数、日期、密码点位均为示意，不得写死为业务数据。字体/图形资源迁入web资源目录，打包后不能依赖others/design或本设计树。
5. 完成每批迁移运行相应真实检查并本地提交；A合并后更新并实测一键启动/演示入口及受影响客户端构建。既有UI通过A验收再启动C，最后按C→B2→D→A2接续；静态设计交付不是A2验收或推送节点。
