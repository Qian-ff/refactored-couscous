# UI-2026.10-v1 状态与行为规范

静态参考：[桌面状态](images/states-sheet.png)、[移动状态](images-mobile/m-states.png)、[登录失败](images/login-error.png)、[CSV结果待确认](images/csv-uncertain.png)。下表是产品实现要求，截图只证明视觉，不证明真实状态转换已接好。

| 状态 / 触发 | 呈现与可做操作 | 必须保留的行为 |
| --- | --- | --- |
| 初次加载 | 局部骨架/简短“正在读取…”与稳定标题；已有数据刷新时保留原内容并标刷新 | 不用随机延时假加载；旧身份内容先清空；同范围刷新不能闪成全页空数据 |
| 空结果 | 说明“当前范围/当前条件没有匹配项”，给刷新、清空或已有新建入口 | 区分无匹配、未加入、待发布；不能把尚未返回当作0条 |
| 请求失败 | 原位错误与重试，保留筛选/合法输入；内容允许保留时注明可能过时 | 不编造成功数据；重试仍受会话、范围和原查询约束，不弹出驱动栈或密钥 |
| 离线 | 顶部/区块警示“网络已断开”，原显示明确过时；恢复后刷新 | 正式管理提交需服务端确认；不能离线宣布导入、审批或保存成功；允许的本页输入仅留内存 |
| 未登录 / 会话过期 | 进入登录并解释需重新登录；安全的站内返回目标可保留 | 旧页面、查询与敏感内存清理；远端退出失败也完成本地清理并反馈 |
| 正在切换身份 | 旧范围退出、显示切换过程，成功后挂新页；失败留明确状态 | confirmSession/switchWorkRole等公共封装保留；旧响应不能回填新身份；不是前端赋权 |
| 无权限 / 撤权 | 明确当前身份不能访问，返回可访问课程/管理入口；不泄露对象详情 | 服务端判权；跨校、学院、班级与目录/班级边界不靠隐藏按钮代替。撤权后新请求重新验证 |
| 服务未配置 | 说明需要服务地址，给现有连接设置入口 | 不伪造在线；保存地址后的重登、会话清理按公共逻辑处理。AI等未实现设置不新增页面 |
| 未开放 / 不支持 | 灰色入口及原因，“未开放”与“当前设备不支持”分开 | 当前学习/助手/记录保留真实状态；以后C/F模块接入时按真实能力声明，不永久写死所有端不支持 |
| 字段校验错误 | 字段旁具体说明，保留其余输入；焦点定位首个错误 | 遵从真实schema：如8–256位密码、不同于临时密码、学生学号专业规则；不发明强制复杂度或丢掉可选字段 |
| 提交中 | 具体动词＋正在处理，相关动作防重复，取消/返回按有无未确认命令处理 | pending不另造第二个请求；保留原请求内容与会话代次，组件卸载后不回填无关页面 |
| 成功 | 在目标区显示真实结果并刷新必要数据，必要时进入新对象 | 只有服务器确认才成功；指定其他主讲开班后没有越权“进入”入口；成功不泄露明文凭据到日志 |
| 修订冲突 | “内容已被他人更新”，给读取最新/保留输入并返回 | 保留revision，不自动把旧表单覆盖新版本；重读后由用户再次确认，不静默丢输入 |
| 结果待确认 | 警示连接中断，给“使用原请求重试”并说明暂不能确认 | 同一命令内容复用Idempotency-Key；不因响应丢失新建批次。内容/身份/学校变化按原封装失效规则处理，先确认原结果 |
| 邀请已生成 | 只在本次成功后显示完整码、范围、有效期及保存/复制入口 | 邀请列表不回显原明文；班级轮换旧码立即失效；账号邀请与班级邀请码分开。复制失败不能显示已复制 |
| 归档 | 显著只读标签与说明，保留有权查看的历史，不提供修改动作 | 停止加入/名单/审批变更和当前学生资料访问；保留成员、教师关系与审批历史。目录归档条件与班级归档分别验证 |
| 转交后失权 | 原主讲看到真实交接成功后返回可访问列表，不保留仍可操作的详情 | 原主讲失去当前班级授权，历史保留；管理员是否仍可见由其独立范围决定 |

## CSV完整流程

账号与班级名单是不同上下文，模板不混用。UTF-8文件读取与直接文本编辑均保留；上限1MiB/500行。先全量预检，错误逐条提供CSV行号/字段/原因；全通过后带真实摘要整批原子提交。修改内容、学校、班级或类型使旧预检失效。预览可从当前CSV本地派生，不能要求服务端增加临时密码明文回包；不回显已保存密码；密码输入/CSV编辑仅用于本次管理员输入，预览、截图、日志、错误和回执遮蔽敏感值，不持久缓存。

提交响应丢失保留原内容与请求标识，用原请求重试确认，不显示“已导入”。若用户编辑/离开，必须明确原结果尚未确认，不能悄悄生成新命令；沿用现有useBusinessAction的幂等行为，不新建重试器绕过。确认成功后再清空内容和预检，并刷新相关账号/名单。

## 搜索、分页和会话

提交的查询与当前输入区分；IME组合不误发，清空、条件变化或目录切换重置对应分页。同身份的旧搜索应取消或忽略；换身份、退出、授权变化按会话代次清旧结果和敏感缓存。不能用前端筛选越权数据或在新范围回填旧结果。

选项只呈现原API支持的条件，不为了匹配图片新增无支持的过滤字段。页面、目录、班级和学校之间切换时清理一次性凭据、教师候选与危险确认状态。所有状态均需桌面键盘及手机触屏验证，移动屏幕不能只截掉错误文本或把重试挤出屏幕。
