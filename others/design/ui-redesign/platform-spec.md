# UI-2026.10-v1 三端适配与真实验收要求

网页、Windows、Android共用设计系统、正式API、权限及领域规则。设计资料不成为客户端运行依赖；D/B把选定样式与资源迁入web源码，A/F从共享前端重新构建，不能维护三套互不一致的页面。

## 1. 共享布局与资源

| 场景 | 规则 |
| --- | --- |
| 宽屏 | 208px侧栏、38px工作区边距，目录/工作区并列；长列表保持服务端分页 |
| 逻辑宽度≤1000px | 184px侧栏，适度减少边距；不截掉表格操作或固定大段文字高度 |
| 逻辑宽度≤700px | 进入手机重排：顶部菜单、记录列表、单列表单；390px为交付参考，不是唯一允许宽度 |
| 手机长页 | 学生底栏固定且预留底部空间；管理页无强行套用的学生底栏，列表按字段标签重排 |
| 长表单 | 标题、动作、正文各有清楚区域，正文独立滚动；桌面抽屉，手机全屏 |
| 字体和图形 | 从包内加载本版字体/原创SVG；来源、许可、哈希保留。不得依赖others设计工作树或公网字体服务 |
| 路由和返回 | D唯一维护HashRouter和注册入口；直链/刷新/前后退/未知与无权限页均真实处理，安全的站内返回目标重新判权 |

正式UI用语统一，不把平台类型写成不同产品版本。未开放入口三端一致，但以后设备能力声明来自实际PlatformBridge，不以静态图永远禁用原生能力。图册CSP的connect-src none用于隔离设计稿，不能复制进需要访问API的正式产品；正式CSP由A/F按真实服务和包内资源配置，不放宽为任意来源。

## 2. Windows

以CSS逻辑尺寸响应窗口。A/F在100%、125%、150%系统缩放及现有最小窗口范围检查：导航、表单、分页、对话框底部、长账号与中文标签不能裁切，必要时切紧凑/移动布局。不能为掩盖溢出擅自提高窗口最小宽度。窗口标题为安研通；保留现有窗口/更新/关闭流程，设计图不授权另换安装器。

键盘Tab顺序符合阅读顺序；Enter提交当前有效表单，Escape关闭可关闭的顶层对话框并恢复焦点；危险命令不因按键冒泡重复提交。滚轮/触控板可以滚动长表单，焦点不被底部动作遮住。CSV选文件/取消、文件路径处理与下载遵循现有平台接口，不把浏览器下载样图当成Windows原生测试。

字体作为包资源随构建，记录包大小、字体加载和首屏；若采用格式转换/子集化，另验证许可与中文字形覆盖。不能修改系统字库、全局SDK或共享依赖来适配本稿。

## 3. Android与手机浏览器

安全区由F确认WebView实际边界后统一处理一次，使用env(safe-area-inset-top/bottom)或平台提供的等价CSS变量，避免原生已留白、网页又重复加边距。学生底栏预留70px加底部安全区；长页最后一条记录/操作能滚到栏上方。顶部和全屏编辑页不盖住状态栏或手势区。

输入区字体16px，控件高46px，触屏命中宽高至少44px。下拉、复选、开关及图标按钮均有完整命中区；原始CSV长文本仅局部滚动，不能把整页横滚当作适配。账号/名单记录显示字段标签，批量导入和搜索筛选保留完整功能。

软键盘出现后，以实际可见视口重排全屏表单/底部动作；F核对当前Activity/WebView的resize行为，必要时在本项目平台适配中处理visualViewport/键盘事件，不能只依赖100vh。当前字段能滚到动作区上方；键盘遮挡时不挤压正文为0、不把保存藏在屏幕外。学生底栏可在已确认键盘打开时暂避，关闭后恢复；dirty输入、选择状态和滚动不无故丢失。

系统返回优先关闭顶层文件选择器/菜单/选择面板，其次关闭编辑区（有未保存输入时按约定确认），再按真实站内历史返回；没有站内历史时交F处理应用返回，不循环压入路由。切到后台/恢复时仍按服务器会话校验权限；布局变化不应新建会话或重复提交。

旋转、长列表、放大字体、选文件取消、手势导航、三键导航、软键盘打开/关闭均由A/F在真实安卓环境验证。设计阶段只做浏览器390px及小视口/24px安全区模拟，不能声明Android键盘或系统返回已经通过。
