# 领域对象与数据边界

## A0 已实现

School、College、User、RoleGrant、LoginSession、CourseCatalog、Course、CourseStaff、Enrollment 已落地。B1已追加Major、完整账号资料、EnrollmentRequest、AccountInvitation、CoreAuditEvent及CommandReceipt；内容与正式学习考试对象仍待对应模块交付。

CourseCatalog/catalog_id 表示课程目录；既有 Course/course_id 始终表示教学班。目录、班级分别保留代码、名称、学院和学校；目录负责人 owner_id 可为空，空值不授予负责人权限。旧班逐一回填独立目录，保留旧 ID、选课、教师关系，不按同名合并。旧 /courses 创建请求自动建立目录与首班，仍可使用。跨校关系有复合外键并由 API 再校验。B1目录管理和开班已复用这些模型，未重复回填。

工作身份为 student、teacher、administrator。student 不能与任何教职/管理授权兼任；teacher 可以兼 administrator。统一写入函数 app/core/grants.py 锁账号行后校验；数据库 role_family_guard 也保护直接与并发写入。B1 所有开通、导入、授权变更复用它。迁移遇历史冲突停止并报告 ID，保留历史，不删角色或拆账号。

LoginSession.default_work_role 固定隐式默认，teacher 兼管理员默认 teacher；撤销后拒绝，不转成管理员。请求 X-Work-Role 经实时授权确认；只有当前身份对应 grants 参与判权。管理员可以组合已获授权的多个学院范围。单独无授权账号不会获得任何业务权限。账号停用、会话撤销和授权变化逐请求检查。

## B1 已实现

学号独立于 username，按学校唯一；专业、姓名等按设计保存，性别、联系方式选填。上级授权教师和管理员，CSV 全量预检后原子提交，提交再次校验权限/冲突/幂等，不覆盖已有密码或授权。首次改密、本人改密、重置后会话撤销已实现；固定演示密码不影响自建账号。创建回执重放也重新检查当前对象权限。

目录负责人管理目录信息及显式审核发布的共享内容；没有全部班级名单、考试、成绩或私有资料权限。班级一名主教师，可有协作教师。协作教师可教学、发布任务、调整本班名单；主教师/有范围管理员负责教师授权、转交、归档。跨学院开班由校管理员协调；普通教师保留创建本人目录及首班的能力。选课多对多，支持邀请码、加入/退出审批、名单导入、原子交接和归档。退班/撤权后保留本人历史记录，不继续开放当前资源。

目录负责人可为已有目录指定本校有效主教师，创建回执只确认原始开班信息，不开放所指定班的私有数据。管理员显式指定的异学院负责人可在目录所属学院开班；把教学班开到目录以外学院仍须校管理员协调。目录共享的具体内容审核发布由C接续。

0.3.2提供学生本人最新Enrollment关系只读视图，状态active/withdrawn/removed与Course.archived独立；同一关系重新加入时复用关系ID，不是完整事件流水。Enrollment当前没有创建/更新时间，不能编造加入、退出、移出时间或用申请时间替代。班级代码/名称是查询时的当前标签，不是历史名称快照。EnrollmentRequest保留真实申请及决定时间；approved申请不保证目前仍在班，当前关系须另查。历史元数据不授予当前课程/名单/资料权限，现行课程授权查询保持原规则。

## C 内容及 B2 学习对象（分阶段实现）

资料子域已在C02公共候选中实现Library、Material、ContentUpload、MaterialVersion、SourceChunk、MaterialReview、MaterialPublication和ContentJob八表，兼容迁移c02d0c00001；是否已进main由A主接收记录确认。成功快照/页段/审核历史不可改写；上传封存回指为延迟约束，重解析复用原件但生成新版本。API使用非owner运行角色，管理/迁移凭据独立。以下题库、关卡、考试和助手对象仍是后续模块，不能由资料接入推导为已实现。

| 对象 | 不变量 |
|---|---|
| Material / MaterialVersion | 文件授权、可提取状态、不可变来源页/段落和文件哈希 |
| Question / QuestionVersion | 草稿→审核发布；答案/解析与学生 DTO 分离，发布版本不可原地覆盖 |
| Library / ShareApproval | 平台公共、学校、学院、目录、班级范围；共享审核绑定具体版本，引用固定版本，复制新草稿 |
| Lesson / LessonVersion | 版本化短课、原创 SVG 场景、choice/hotspot/order 活动；教师预览与学生响应分离 |
| Assignment / Assessment | 绑定教学班；发布固定内容、分值、关键题、时限、次数和规则版本 |
| Attempt / Answer | 服务端保存 revision/时间/截止；幂等开始和提交；刷新/重登续接同次 |
| LearningProgress | 服务端依据真实互动判定完成、顺序解锁、徽章和错题；客户端不能声明达标 |
| TrainingRecord | 同次成绩≥80且关键题全对并完成必修关卡；默认12个月，关联实际达标作答/规则 |
| ProviderProfile / Selection | 学校主动选择平台或完整独立配置，未选择为未配置；测试后启用，密钥只在服务端 |
| Job / AuditEvent | 有授权的状态、取消、故障、幂等及操作审计，结果读取再鉴权 |
| AlertEvent / CaseDraft | 原媒体留本地；去身份摘要形成草稿，教师确认审核；完整监控由 E 实现 |

正式考试默认60分钟、最多3次，教师发布前可调整；多选全对得分，否则0。展示最高成绩，达标不能跨次拼接关键题和总分。超时按服务端已保存答案交卷；关页面不暂停时钟，未上传草稿不算已保存。练习可即时反馈；终测关考后教师统一公布答案解析。已发布规则/题目/成绩随新版本保持可追溯，重复提交不重复占次/发记录。

存在有效正式作答时，暂停该学生账号跨班/会话/设备的全部平台 AI 辅导。其他账号不受影响；交卷/超时/合法中止后重算，如有其他有效考试继续暂停。B2 提供服务端状态，C 在问答、续问、任务执行和结果返回均验证；状态不可核实则学生辅导暂停。C 可先用教师账号验收，B2 联合验证后才开放学生链路。

跨校隔离优先于所有共享、搜索计数/分页/片段/建议词、下载及任务读取。公共库不可成为私有内容跨校通道；同目录双班也不互通名单、考试与成绩。选课不授予监控权限。
