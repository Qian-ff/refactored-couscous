# 安研通 A1 使用指南

## 先打开哪个

在本机 D:\SafeLabPlatform 双击以下任意入口。它们用于已经初始化的本机项目，需保留完整项目目录及本机已安装的 Docker、Node、Python、SDK；不是可单独复制到其他电脑的安装器。

| 文件 | 用途 |
|---|---|
| Open-Web.cmd | 自动准备后端，打开浏览器中的安研通；推荐先体验这个 |
| Open-Windows.cmd | 自动准备后端，打开 LabConnect.exe |
| Open-Android.cmd | 自动准备后端，显示安卓模拟器并安装、打开安研通 |
| Open-A1.cmd | 菜单：1网页、2电脑客户端、3安卓模拟器、4同时打开三端、0退出 |

启动器复用健康服务；后端未就绪时启动已有 Docker Desktop、等待 PostgreSQL、执行当前版本迁移并启动 API。网页入口还会启动本机网页服务。不会自动下载依赖、构建包、重置演示密码或清空数据库。失败时窗口保留错误信息；后台服务日志在忽略的 others/reports/launcher。

网页地址为 http://127.0.0.1:5173。网页包 dist/index.html 通过 HTTP/HTTPS 服务加载，直接双击 file:// 文件会被浏览器拦截 ES 模块。日常本机体验直接用 Open-Web.cmd。

## 登录

学校代码填写 demo-a。密码打开本机忽略文件 others/runtime/demo-accounts.json，读取 password 字段；不要把该文件提交到 Git 或公开发送。

| 身份 | 账号 | A1可体验的操作 |
|---|---|---|
| 教师 | teacher | 查看授权课程，新建本人课程 |
| 学生 | student | 查看已获授权的课程，没有新建课程按钮 |
| 学校管理员 | admin | 查看本校课程，新建课程并选择学院/主教师 |
| 学院管理员 | college | 在被授权学院内查看和新建课程 |

有完整的第二学校隔离测试账号 demo-b/admin_b，但请先完成下面的普通体验流程。

## 推荐使用流程

1. 双击 Open-Web.cmd，用 demo-a / teacher 登录。
2. 点击“新建课程”，填写唯一的课程代码，例如 DEMO-001，名称填写“我的安全演示课程”，保存。
3. 双击 Open-Windows.cmd，以 demo-a / admin 登录。在课程列表点击刷新，应看到刚才创建的课程；可以比较两个端的数据一致性。
4. 双击 Open-Android.cmd。安卓模拟器第一次冷启动会较慢，等脚本显示 Ready。登录页“服务连接设置”应为 http://10.0.2.2:8000。
5. 安卓先用 teacher 登录、查看该课程；也可以再创建一门课程，然后回网页点击刷新查看。
6. 退出后用 student 登录。此账号仅看到已经选入的示范课程，不会因为教师新建课程就自动加入。A1没有自助加退课界面。
7. 点击退出登录可切换身份。关闭或刷新客户端后需要重新登录；已保存课程保留在统一数据库。

每个端都能切换上述账号，不是一个端只对应一种身份。课程是否可见由服务端当前授权决定。

## 当前能做什么

A1开放真实登录/退出、身份和授权、按权限读取与新建基础课程、三端统一保存及刷新读取。不同学校数据隔离；学生只能读取已授权课程。

题库、闯关、考试、语音、监控、加退课审批、完整个人资料和密钥管理仍由后续模块实现。标为“筹备中”的入口不会执行真实业务，不把这些入口当作已交付功能。

## 关闭、重新打开和常见情况

- 关闭浏览器、Windows客户端或模拟器，只关闭相应界面。数据库和后端可能仍在后台运行，保存的课程不会因此删除；重启电脑后再次双击对应入口。
- 不要手动删除 Docker 数据卷。启动器不会创建系统自启动项，也不会改全局 Java/Python 设置。
- 网页能显示但登录提示连接失败：确认后端已启动。网页开发版/Windows测试包使用 http://127.0.0.1:8000；安卓模拟器使用 http://10.0.2.2:8000。
- 模拟器提示 System UI 无响应：启动脚本只对已识别的该系统提示选择 Wait 并有限重试；持续失败会报错，不自动忽略其他应用异常。
- 已有无窗口测试模拟器时，可先执行 `& 'D:/AndroidSDK/platform-tools/adb.exe' -s emulator-5556 emu kill`，再双击 Open-Android.cmd 显示窗口；其他设备不受影响。
- 依赖或包缺失时，按提示在根目录执行 Bootstrap.ps1 或相应 build 命令。详细构建与证据见 a1-handoff.md。
- 生产网页包要求 HTTPS 后端；本机演示优先使用一键入口，不修改浏览器安全选项。安卓实体机和正式安装器留后续验证。
