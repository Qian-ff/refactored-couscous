四、关卡与预览
六个首批主题：通识“入室与个人防护、设备用电与行为规范、应急处置”；化学“试剂标签与储存、操作与通风、废物与泄漏应对”。
制作原创二维SVG与复用hotspot/choice/order互动，键盘和触屏可用，排序提供非拖拽方式。按C固定版本StudentLesson展示短课/场景/互动/解释来源，学生不含correct_ids/评分规则；按B正式结果做顺序解锁、纠错、过关、徽章、薄弱点与复训。默认每课三关，必修互动服务端确认才过关；练习可反复，数量主题组合由数据驱动。后续AI自定义关卡留扩展入口/版本，实际生成非本轮完成条件。
提供TeacherLessonPreview渲染器，由集成处注入C编辑器renderPreview，避免C-D循环导入。有权教师管理可试操作/看答案，预览无正式Attempt/进度/成绩/徽章/记录写入；学生用独立账号实测。

五、考试、助手及记录
接B正式规则、剩余次数、进行中作答、保存/续答/提交、判分和培训记录。时限/次数/分数线/关键题/有效期/答案公布读服务端，不硬编码默认值作判定。显示服务器deadline/server_time，关闭页不停时；保存收到revision/saved_at才显示成功。断网草稿只当前页内存并标未保存，恢复按服务端版本处理冲突，重登续同次不占额；提交幂等，服务器确认后显示交卷。超时由服务器按已保存答案结算，不假装离线已上传。
成绩/达标/历史版本/关考公布按服务器结果；展示分项反馈与复训。正式考试时该学生全部平台AI辅导暂停，其他账号正常，状态不可核实暂停；页面接C真实限制，不能仅按钮隐藏。
