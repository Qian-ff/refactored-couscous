# G：独立验收任务书

请作为 SafeLabPlatform 的 G 角色工作。本任务以根 AGENTS.md、设计基线与真实接口契约为准，A1 的实际实现、验收状态与可交接基线见 others/docs/a1-handoff.md；后续模块按已发布基线继续开发。

本次既有UI改版验收遵循[批准/冻结门禁](../ui-redesign-coordination.md)：分别核对用户批准、功能映射、网页真实回归和原生运行，渲染通过或图片存在不作为用户批准。保留首次改密、角色收窄、CSV幂等重试、搜索竞态、审批/交接/归档及三端布局的检查证据；实现缺陷交责任角色。UI设计改动仍须frontend-design与批准规范；G推理设置保持原安排。

## 开始前

1. 打开自己的独立工作区 others/worktrees/qa，确认当前分支为 task/qa。
2. 读根 AGENTS.md、others/docs/design.md、others/contracts/README.md 和 ownership.json。
3. 当前基线为 checkpoint-1，包含最新一键工具及三角色/搜索要求；从交接报告核对后，在干净的本分支合并并确认 contains_baseline=true 再开始实现。

## 本角色任务

1. 从权限隔离、学习达标和监控闭环建立可复跑 API/E2E/故障测试。
2. 覆盖跨学院课程、变更教师、退课历史、重复提交、接口失败和密钥边界。
3. 检查三端安装、手机排版、录音、摄像头和包内敏感配置。
4. 独立汇总复现步骤、版本和证据；由责任聊天修复实现，自己复测。
5. 覆盖三平台乘三角色的首页、导航、业务权限和课件搜索；验证检索总数/片段/建议词、预览下载直链、跨校/学院越界、撤销授权和切换身份缓存隔离。验收标准见设计第11节及 acceptance.md。
6. 每次功能集成复验通用及本轮一键入口，核对实际打开的产物版本和新增功能。向 A 提交检查证据，由 A 按 git-workflow.md 的三个已授权节点推送，不自行上传分支。
