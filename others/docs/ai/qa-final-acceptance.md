# G：集成后独立验收工作包

当前未登记G聊天，不自动创建或唤醒。既有历史验收树`others/worktrees/qa`和`task/qa`保留；A达到集成里程碑时给用户手动创建G聊天入口，核对登记树/分支，保留历史后合并A完整执行基线才启动，不重建旧树。路线及前置见[首版流程](../delivery-workflow.md)；G不写产品修复，缺陷交原责任作者，修复后独立复测，A副自测不替代G。

输入必须是A已接收的完整main SHA、迁移/真实契约版本、构建产物版本及实际访问方式。核对源码/运行服务/客户端对应；不以设计图、mock、构建成功或旧云版本证明端到端通过。

- 权限：学校隔离、学院范围、跨学院课程授权、同目录双班、撤权/退班/换师/停用、草稿/答案隔离、搜索计数/片段/直链与文件访问。
- 内容/学习：真实上传解析/发布搜索/定位预览下载；固定题目/关卡/规则与历史不可变，六关互动、服务器判分、次数并发、保存revision、续答/超时、幂等记录、同次关键题达标、失网真实反馈。
- 助手：账号级考试暂停跨班/设备/旧会话、历史/引用和任务全程，未知状态暂停学生；教师真实问答；三端真实录音—确认—问答—引用—中文播报。
- 监控：本地媒体、去身份摘要、人工确认/案例草稿、告警授权，误报/漏报/延迟及已知限制；不声称替代消防系统。
- 交付：Web/Windows/Android乘三身份九组合、触屏/键盘/返回/权限/下载，一键启动和演示、源码契约产物一致、云端真实联调、数据库公网关闭、迁移/备份/恢复证据及许可。

按现有QA范围本地提交报告，列严重程度、最小复现、责任角色、预期/实际和证据；作者最多三轮普通修复后仍失败则集中交A，不降低验收范围。最终给A通过/未通过矩阵和剩余事项，由A决定发布和既有授权checkpoint。
