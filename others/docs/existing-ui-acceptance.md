## 体验入口

双击根Open-DUI.cmd打开正式网页；Open-Web、Open-UI、Open-BUI及原Windows/Android入口复用同一主线启动器。网页127.0.0.1:5173，API127.0.0.1:8000；模拟器使用10.0.2.2:8000。账号从主树忽略的others/runtime/demo-accounts.json读取。手机手动体验继续使用android/Open-Emulator.cmd，包及数据保存在忽略区。

1. 学生在“我的课程”使用班级邀请码加入。直接加入显示在班，需审批时显示待审批；学生账号邀请只用于开通账号，两种邀请分开。
2. 从课程卡进入教学班详情，退出需确认；退出审批未通过前仍在班。教师/管理员在原班级审批入口处理，学生刷新“班级申请与历史”查看真实结果或撤销待处理申请。
3. 在历史页按名称、代码、关系或归档筛选，查看本人最新持久关系及真实申请时间。已退出/移出/归档不开放当前班级资源；approved申请不作为目前在班证明，也不编造加入/退出时间线。
4. 教师/管理员继续原七条注册页面中的组织、账号、邀请、CSV、目录/班级、名单/审批及教师交接。离线、失败、revision冲突、响应丢失同键重试和撤权由真实接口与会话处理。
