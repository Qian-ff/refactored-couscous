## 公共组件与业务机制

- BusinessPage 消费 PageContainer，提供唯一 main / h1；公共壳统一一次工作区边距。Section消费Panel，Button、Field、Notice、StatePanel、SearchFilters、Pagination、Dialog使用D原导出。
- BusinessRecords只做领域列映射：桌面语义表格，手机消费公共RecordList，同一份真实字段与动作。FilterFields只折叠手机筛选，不取消条件或请求。
- EditorDialog消费公共Dialog：桌面侧置、手机全屏，标题固定、正文独立滚动；未保存关闭确认。危险确认包装原命令，只有服务器成功后关闭。冲突保留输入，用户明确读取最新后再确认保存。
- **SessionPage、useBusinessAction、useBusinessQuery与组件基线函数文本逐字一致**，哈希在 `hook-preservation.json`。内存会话、身份代次、取消、竞态保护、幂等键及revision未重写。
- API实际来源审计只记录origin和数量，不保存请求体、查询值、密码或认证头。所有9场景实际浏览器API来源均要求为本树 `http://127.0.0.1:8001`；不能只以测试环境变量代替实际请求证明。
