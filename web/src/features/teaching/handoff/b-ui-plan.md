# B-UI 迁移计划与自审

起点 `d-ui-components-ready` = `27c1e385d2e0b97ce5880e0230bae2be7aa1a5c1`，B 当前树已纯快进同步并保留所有旧提交；契约 0.3.1。仅改 admin / teaching 及其测试、交接，不改公共入口、组件库、SDK、后端、依赖。公共组件契约及 UI-2026.10-v1 视觉、移动、状态、功能清单已读。

## 第一遍：沿用批准方案

- 颜色：实验青 #087F8C、协同蓝 #2563EB、工作底 #F5F8FA、纸白 #FFFFFF、墨色 #172B3A、结构线 #DCE7EB。状态色使用已交付组件，不另造主题。
- 字体：公共包内 LabNoto / Noto Sans SC；桌面标题32、手机26，正文15；手机输入16，所有触控至少44px。
- 教师与管理员课程页：左侧目录索引（独立查询、分页、全部授权班级），右侧教学班工作页（目录筛选、当前/历史、搜索、分页）。手机目录折叠，班级用标签化记录。
- 组织、账号、邀请、名单和审批：桌面保留连续表头与记录，手机消费公共 RecordList，保留每个字段及动作。B 的适配只负责领域列映射，不另建公共组件库。
- 编辑：消费公共 Dialog，长表单桌面侧置、手机全屏；原生字段、只读编码、合法取消、未保存提示；风险动作短确认。课程仍归档，不增加删除接口。
- 公共壳提供唯一工作区边距，PageContainer提供唯一main/h1；Section消费Panel。Button、Field、Notice、StatePanel、SearchFilters、Pagination均使用D现有导出。

```
桌面：公共导航 | 目录索引 | 教学班工具条、连续记录、分页
管理：公共导航 | 页标题与任务 | 范围搜索、完整记录 | 右侧编辑
手机：公共顶栏 | 目录展开/范围搜索 | 标签化记录与操作 | 全屏编辑
```

## 第二遍：对照批准方向修订

旧页面的双main、整页padding、重复身份标签和通用渐变卡片不沿用；记录、结构线与目录索引体现实验记录簿。管理列表不增加器材插图和虚构统计；沿用D壳及包内字体，不另造身份层。桌面不能以移动卡片替代全部表格，手机不能以整表横滚代替字段重排。

业务钩子 `SessionPage` / `useBusinessQuery` / `useBusinessAction` 保持原实现；视觉适配只调整消费者和展示。接口、参数、载荷、revision、幂等签名及同键重试保留。编辑/搜索状态改为对话框或工具条时仍由原页面维护，权限继续由服务端校验。
