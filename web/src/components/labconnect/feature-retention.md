# D-UI 第一批功能保留矩阵

本表基于契约0.3.1及批准UI；“保留”与“本轮已验收”分别记录，不以设计图覆盖率代替功能检查。

| 功能 | 已有实现/当前入口 | 本轮动作 | 后续责任方/验收 |
|---|---|---|---|
| 登录、服务地址、退出、身份确认 | 真实auth与共享api.ts | 新账号页和身份壳接入；退出失败清本地、直链及切换 | D本批真实接口；A/F原生 |
| 强制/普通改密 | change-password撤销旧会话 | 强制门禁、成功后重登；固定账号密码不改 | D本批 |
| 学生账号邀请注册 | invitations context/register，已有后台邀请页面 | 登录入口新增；受限合法专业、自设密码、注册不自动登录 | D本批；B邀请管理视觉迁移 |
| 本人资料 | GET/PATCH profile，revision | 只改性别/联系，冲突重读；其余只读 | D本批 |
| 学生课程查询 | /courses，q/offset/limit | 迁入正式学生页面，保留学院/代码/名称/主讲/分页 | D本批 |
| 学生加入/退出班级 | 真实class命令，当前未有正式学生入口 | 完整保留；本批不冒称有入口 | D二次整合，既有UI验收前补齐 |
| 学生申请、申请撤销 | 真实join/leave/request接口 | 完整保留 | D二次整合，既有UI验收前补齐 |
| 学校/学院/专业 | B OrganizationsPage | 正式注册导航可达，B文件不改 | B展示迁移→D二次整合→A/F |
| 账号、资料、角色授权、停用/重置 | B AccountsPage | 正式导航可达；保留上级范围与服务端规则 | B展示迁移→A/F既有UI |
| 课程目录/教学班、查询及分页 | B CoursesPage | 正式导航可达；目录与班级语义不合并 | B展示迁移→D二次整合 |
| CSV预检/原子提交/同键重试 | B CsvImporter及业务页 | 原实现保留，未复制/替换业务逻辑 | B回归→A既有UI |
| 名单、审批、教师协作 | B ClassManagementPage | 参数路由注册，字段和动作原样保留 | B展示迁移→A既有UI |
| 教师交接、邀请、归档 | B ClassManagementPage/InvitationsPage | 原接口和revision保留；课程删除保持归档 | B展示迁移→A既有UI |
| 上传/分层题库/导入导出/AI草稿/审核/固定版本/检索/学校API配置 | C完整任务，尚未交付 | 保留任务；当前不制造占位HTTP或数据 | A放行后C |
| 六主题互动、考试保存续答/超时/判分/进度/培训记录 | C/B2/D后续任务 | 仅显示真实未开放状态 | C→B2→D后续→A2 |
| 悬浮助手对话/历史/引用/录音确认/播报 | 已批准v1.1，业务未开放 | 保留未开放入口，不注册独立助手页 | D唯一宿主/C业务/F适配/B2考试限制 |
| 监控预警 | E后续任务 | 当前未开放，不返回伪造成功 | E/A/F后续 |
| 正式客户端发布、云端更新 | F/A职责 | 本批不提前实现，不重新发布旧包 | A/F既有UI及正式发布阶段 |

所有B页面保留原有请求、会话、权限、查询竞态、幂等和修订规则。设计资料保持原字节。三端共享前端；本批只交D组件和网页证据，B完整展示迁移及原生运行不计为本批已完成。
